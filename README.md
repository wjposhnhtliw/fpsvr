## 🕹️ Overview

fpsVR displays a persistent performance overlay inside any SteamVR game showing FPS, frametimes, GPU and CPU usage, VRAM, and reprojection events.

Whether you're a newcomer or a veteran, fpsVR provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Frametime Graph** | Live rolling frametime graph to spot performance spikes |
| **GPU and CPU Stats** | Real-time utilisation, temperature, and clock speed display |
| **Session Logging** | Saves full performance logs for post-session analysis |
| **Reprojection Counter** | Highlights frames that trigger ASW or reprojection |
